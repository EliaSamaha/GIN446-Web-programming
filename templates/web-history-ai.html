Web Key Milestones

The World Wide Web, invented by Sir Tim Berners-Lee in 1989, is a global information space where digital documents and resources are identified by URLs and interlinked via hypertext. Operating over the internet's physical infrastructure through protocols like HTTP/HTTPS, it evolved from a static database into an interactive, ubiquitous ecosystem — the backbone of modern commerce, communication, and social life.

The World Wide Web Proposal

1989

Berners-Lee describes CERN as a place of thousands of creative people working toward common goals, undermined by high staff turnover that constantly erases institutional knowledge. His proposal argues that a "web" of linked notes, unconstrained by any fixed hierarchy, could let a pool of information grow and evolve alongside the organization itself.

Source: w3.org/History/1989/proposal.html

First Website, Server, and Browser

1990 – 1991

Berners-Lee brings his proposal to life at CERN. The world's first website, dedicated to the World Wide Web project itself, runs on his own NeXT computer — the same machine acting as the first web server.

Source: web30.web.cern.ch/web-history.html

Public Royalty-Free Release & Mosaic

1993

CERN places the World Wide Web's source code in the public domain, free of charge. In the same year, NCSA releases the Mosaic browser, which adds inline images and brings browsing within reach of non-technical users for the first time.

Source: cds.cern.ch/record/1164399

W3C Foundation & Commercial Expansion

1994 – 1995

As companies pour growing resources into the web, the case for a coordinating body becomes urgent. Berners-Lee forms the World Wide Web Consortium and leads it toward a consistent architecture that can keep pace with rapid progress across web standards, browsers, and devices — assembling a community of peers to steer where the technology moves next.

Source: w3.org/about/history

Indexing the Web & Google's PageRank

1998

Google launches, replacing hand-curated link directories with search indexing built on page relevance and link connectivity — a shift that makes the sprawling, unstructured web navigable at scale.

Source: sciencedirect.com

Mobile Web & Responsive Design

2007 – 2010

The rise of smartphones pulls traffic away from desktop computers, pushing the industry toward media queries, fluid grids, and the responsive design standards needed to make one web work on every screen size.

Source: alistapart.com/article/responsive-web-design

Modern Web Application Era

2013 – present

Single-page application frameworks like React arrive in 2013, joined by HTML5 video, strict HTTPS encryption, and Progressive Web Apps. Together they push the web to match the capability once reserved for native desktop and mobile applications.

Source: html.spec.whatwg.org/multipage
