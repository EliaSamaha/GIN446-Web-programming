Web Key-Milestones

-The world wide web proposal: (1989)

CERN is a wonderful organization. It involves several thousand people, many of them very creative, all working toward common goals. Although they are nominally organized into a hierarchical management structure, this does not constrain the way people will communicate, and share information, equipment and software across groups. A problem, however, is the high turnover of people. When two years is a typical length of stay, information is constantly being lost. In providing a system for manipulating this sort of information, the hope would be to allow a pool of information to develop which could grow and evolve with the organization and the projects it describes. For this to be possible, the method of storage must not place its own restraints on the information. This is why a "web" of notes with links (like references) between them is far more useful than a fixed hierarchical system.

www proposal

-First Website, Server, and Browser(1990-1991)

Sir Tim Berners-Lee, a British scientist, invented the World Wide Web (WWW) in 1989. The first website at CERN - and in the world - was dedicated to the World Wide Web project itself and was hosted on Sir Berners-Lee's NeXT computer.

First website

-Public Royalty-Free Release & Mosaic(1993)

CERN made the World Wide Web source code available in the public domain free of charge. Concurrently, NCSA released the Mosaic browser, which enabled inline images and made browsing accessible to non-technical users.

Free Release

-W3C Foundation & Commercial Expansion(1994-1995)

In 1994, the decision to form the World Wide Web Consortium came at the urging of many companies investing increasing resources into the web. Sir Tim Berners-Lee started leading the essential work of the Web Consortium team to foster a consistent architecture accommodating the rapid pace of progress in web standards for building websites, browsers, devices to experience all that the web has to offer. In founding the World Wide Web Consortium, Sir Tim Berners-Lee created a community of peers. Web technologies were already moving so quickly that it was critical to assemble a single organization to coordinate web standards.

W3C Foundation

-Indexing the Web & Google's PageRank(1998)

Google launched, replacing simple link directories with search indexing algorithms based on page relevance and link connectivity.

Indexing

-Mobile Web & Responsive Design(2007-2010)

The proliferation of smartphones shifted web traffic away from desktop computers, prompting media queries, fluid grids, and responsive web design standards.

Responsive design

-Modern Web Application Era(2013-present)

Single-Page Application (SPA) frameworks like React (2013), HTML5 video, strict HTTPS encryption, and Progressive Web Apps (PWAs) elevated the web to match native desktop and mobile application capability.
